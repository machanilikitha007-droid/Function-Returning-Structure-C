# Function Returning a Structure in C

This program demonstrates how a function can return a structure.
The returned structure contains student details.

## File

return_structure.c

## Concepts Used

- Function definition
- Function call
- Structure
- Returning a structure
- Structure members

## How to Run

gcc return_structure.c -o return_structure
./return_structure

## Sample Output

Student Name: Likitha
Marks: 85
